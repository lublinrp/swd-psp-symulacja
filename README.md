# SWD PSP — symulator przeglądarkowy

Nieoficjalna symulacja do treningu i Fire RP. Nie łączy się z systemami PSP ani rzeczywistą łącznością.

## GitHub Pages
1. Utwórz publiczne repozytorium.
2. Wgraj wszystkie pliki z archiwum do katalogu głównego.
3. Otwórz Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Dane są przechowywane lokalnie w przeglądarce i nie synchronizują się między użytkownikami.
